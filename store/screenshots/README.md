# Shipping-build screenshots

Capture these screens from the signed release build with clean status bars and no personal content:

1. Home and the 21-scene catalog.
2. A guided scene before answering.
3. Correct-answer or completion feedback.
4. Mira with a non-sensitive sample conversation and the Report control visible.

Save opaque PNG files at these exact paths:

- Android phone, 1080×1920: `android/01-home.png` through `android/04-mira.png`.
- iPhone 6.9-inch, 1320×2868: `ios/01-home.png` through `ios/04-mira.png`.

The v1 configuration is phone-only, so no iPad screenshot set is required. Do not use web renders or mockups in place of the shipping Android and iOS builds.
