- The app is Bolo, a Hindi speaking practice app. Its iOS app ID is com.bolo.hindi.
- A new install opens on onboarding. If an iOS prompt "Open in Bolo?" or an Expo developer menu shows first, select Open, Close, Dismiss, or the X button to reach the app.
- Onboarding has three screens, each with a button at the bottom:
  1. "Hear this": the word Namaste plays. Under "Which reply fits?", select the Namaste reply. Then select Continue.
  2. "Where are you starting?": the defaults are fine. Select Continue.
  3. "Meet Asha": select Start practicing.
- After onboarding, the first lesson opens. Its close button is labeled "Close lesson". Closing it shows the Today screen.
- The tab bar has four tabs: Today, Asha, Phrases, Progress. Settings is not a tab. It opens from the gear button labeled "Settings" at the top of Today, and its screen shows "Learning preferences".
- A lesson shows "Turn N of M" at the top. Each turn shows answer choices. Select a choice, then select Continue. The last turn's button reads Finish. A wrong choice can add a short review ("Review N of M") before the finish.
- Turns come in four kinds. After each, select Continue (Finish on the last turn):
  - Answer choices: select one choice.
  - Word order ("Your sentence appears here"): tap the Hindi word tiles in sentence order, then select "Check my sentence". "Undo last word" and "Clear sentence tray" fix mistakes.
  - Recall: select "Reveal the Hindi answer", then "Got it".
  - Say aloud ("No microphone on this turn"): select "I said it". Nothing is recorded.
- The finish screen shows "You did it!" and "You finished “<lesson title>.”".
- Out of scope for every lane: live voice with Asha, the microphone, "Talk with Asha", "Type to Asha", "Enable live practice", and any consent sheet. If a microphone permission prompt appears, select Don't Allow.
- Do not delete data. Do not select "Delete my Bolo data", and do not change settings.
